# AI Use Statement
This document records the use of artificial intelligence tools during this project, following the course requirements.

AI tools were used for three main tasks in this collocation analysis project on the term “junzi” in *The Analects* and *The I Ching*.
1. **Code development**: AI assisted in drafting, debugging and modifying Python scripts for text preprocessing, collocation extraction, KWIC concordance generation, and exporting results to CSV files. I revised the generated code manually, tested each function in GitHub Codespaces, adjusted window parameters and cleaned the output corpus myself.
2. **Structural planning**: AI offered suggestions on report organisation, including the arrangement of introduction, results and limitation sections. The final outline and research logic were confirmed by myself.

All AI outputs were reviewed, edited and verified against my own corpus experiment results. No AI-generated content was copied directly without revision. The core analysis, interpretation and conclusions are my own work.
