# Assignment-1
# DHG 502 Assignment 1: Collocation Analysis of junzi in *The Analects* and *The I Ching*
## Research Question
This project uses corpus collocation methods to compare how the concept of **junzi** is framed in two foundational Chinese classic texts: *The Analects* and *The I Ching*. It explores what neighbouring words reveal about the different definitions, moral expectations and behavioural ideals associated with junzi across these two works.

## Source Information
- **Texts**: *The Analects* and *The I Ching*
- **Source URL**: Project Gutenberg digital plaintext editions
- **Rights**: Works are in the public domain.
- **Corpus selection**: Only the main body text of each classic is retained. All translator prefaces, footnotes, commentaries and appendices are removed to preserve the original textual vocabulary. No partial sampling; the full cleaned text of each work is used for collocation extraction.
